## ⚙️ Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Parvathy-algo/portfolio-website.git
   ```
2. Open the project folder:
   ```bash
   cd portfolio-website
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
